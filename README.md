# 🏨 Hotel Booking Data Analysis Project

## 📌 Overview
This project focuses on analyzing hotel booking data to uncover insights into **booking trends, cancellations, customer behavior, and revenue performance**.  
The project includes data cleaning and preprocessing using **Python**, data analysis using **SQL (SSMS)**, and interactive dashboard creation using **Power BI**.  
The analysis helps stakeholders make **data-driven decisions** in the hospitality industry.

---

## 🚀 Tech Stack
- 🐍 Python (Pandas, NumPy)
- 🗄 SQL (Microsoft SQL Server)
- 🛠 SQL Server Management Studio (SSMS)
- 📊 Power BI

---

## 🔄 Project Workflow

### 1️⃣ Data Collection
- Collected hotel booking dataset in CSV format

### 2️⃣ Data Cleaning & Preprocessing (Python)
- Handled missing values
- Removed duplicates
- Converted data types
- Standardized column names
- Performed feature engineering
- Handled outliers

### 3️⃣ Data Analysis (SQL - SSMS)
- Calculated KPIs
- Analyzed booking and cancellation trends
- Performed customer segmentation analysis
- Conducted market segment analysis
- Extracted business insights using SQL queries

### 4️⃣ Data Visualization (Power BI)
- Built interactive dashboards
- Used slicers for filtering
- Created charts and KPI cards
- Visualized booking trends and customer insights

---

## 📊 Key KPIs
- ✔ Average ADR: **94.95**
- ✔ Total Cancellations: **11.12K**
- ✔ Average Lead Time: **92.68**

---

## 🔍 Key Insights
- 📌 High cancellations observed in **no-deposit bookings**
- 📌 Online travel agents contribute the most bookings
- 📌 Certain customer segments have higher cancellation rates
- 📌 Country-wise trends show variation in booking demand

---

## 🗄 SQL Analysis (SSMS)

Performed data analysis using **Microsoft SQL Server** and **SQL Server Management Studio (SSMS)**.

### 🔹 Key SQL Operations
- Data extraction using SELECT statements
- Filtering using WHERE clause
- Aggregations using COUNT and AVG
- Grouping using GROUP BY
- Sorting using ORDER BY
